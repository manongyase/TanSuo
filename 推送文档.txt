※※※ 注解：标记 [手动] 的步骤无法自动化，需要在操作前手动完成 ※※※

【前提条件】
  [手动] 1. Watt Toolkit 已安装
  [手动] 2. 打开 Watt Toolkit → 网络加速 → 勾选 GitHub → 点击加速
           （Hosts 模式，不需要设置本地代理端口）

【日常推送 3 步】
  [手动] 打开 PowerShell，执行：

  cd F:\TanSuo
  git add .
  [手动] git commit -m "描述你的改动"

  ---- 关键：绕过 Watt Toolkit SSL 问题 ----
  git config --global http.sslVerify false
  git push -u origin master
  git config --global http.sslVerify true
  ------------------------------------------

【首次初始化（仅第一次用）】
  cd F:\TanSuo
  git init
  git add .
  git commit -m "feat: 初始化"
  git remote add origin https://github.com/manongyase/TanSuo.git
  git branch -M master
  [手动] 然后按「日常推送」的步骤推一次

【常见问题】

  Q: 提示 "credential-osxkeychain is not a git command"
  A: 无害警告，git 配置里混入了 macOS 的凭证管理器，不影响推送结果。
     想彻底消除：git config --global --unset credential.helper

  Q: 提示 "Failed to connect to github.com port 443: Timed out"
  A: [手动] Watt Toolkit 没开 GitHub 加速，回去开一下。

  Q: 提示 "SSL certificate problem"
  A: 按文档里的 sslVerify false → push → true 流程走。

  Q: 提示 "src refspec master does not match any"
  A: 还没有任何提交，先 git add . && git commit -m "init"
